# BLACK PAW — сайт агенції

Статичний односторінковий сайт. Ніякої збірки, фреймворків і залежностей — просто відкрийте `index.html`.

```
index.html          вся сторінка: розмітка, стилі, скрипти, обидві мови
video/
  reel-1..4.mp4     ролики в портфоліо
  reel-1..4.jpg     обкладинки (poster) до них
```

## Як правити тексти

Усі тексти лежать у словнику `I18N` наприкінці `index.html`:

- `I18N.en` — англійська (мова за замовчуванням)
- `I18N.uk` — українська

Ключ у словнику збігається з атрибутом `data-i18n` у розмітці. Щоб змінити напис — правте
рядок у **обох** словниках. Наприклад заголовок секції кар'єри — це `career.h2`.

## Що треба замінити перед публікацією

| Де | Що |
|---|---|
| `og-cover.jpg` | картинка прев'ю 1200×630 px — покласти в корінь репозиторію саме під цією назвою (на неї вказує `og:image`) |
| `vi.aicreation@gmail.com` | пошта, якщо зміниться (зустрічається у 4 місцях) |

## Мова за замовчуванням

Англійська для всіх. Логіка вибору — у функції `detect()`:

1. мова, яку відвідувач сам обрав раніше (зберігається в браузері);
2. `?lang=uk` або `?lang=en` в адресі;
3. інакше — англійська.

Якщо колись захочете, щоб українські браузери одразу бачили українську — у файлі поруч
із `detect()` лежить закоментована функція `fromBrowser()` з інструкцією.

## Додати ролик у портфоліо

1. Покладіть `reel-5.mp4` і обкладинку `reel-5.jpg` у `video/`.
2. Скопіюйте будь-який блок `<article class="reel">` у секції `#work` і змініть шляхи.
3. Додайте ключі `work.meta5` / `work.play5` в обидва словники.

Вертикальний ролик — `class="reel"`, горизонтальний — `class="reel reel--wide"`.
Обкладинки: вертикальні 1080×1920, горизонтальні 1920×1080, до ~250 КБ.

## Публікація на GitHub Pages

```bash
git remote add origin https://github.com/VasylD-automation/axion-site.git
git branch -M main
git push -u origin main
```

Далі в репозиторії: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
За хвилину сайт буде на `https://paw.black` (домен задано у файлі `CNAME`).

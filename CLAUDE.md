# BLACK PAW — карта проєкту

Орієнтир для Клода. `README.md` поруч описує **як правити тексти**; цей файл — **де що лежить
і що зламається, якщо правити неуважно**.

---

## Що це за проєкт

Односторінковий сайт агенції BLACK PAW — AI-відео для брендів, студій та агенцій.

- **весь сайт — один файл `index.html`**: розмітка, стилі, скрипти, обидві мови
- збірки немає. Ні npm, ні бандлера, ні залежностей. Правка сайту = правка цього файлу
- хостинг: GitHub Pages, гілка `main`, корінь репозиторію
- домен заданий у `CNAME` → `paw.black`
- деплой: `git push` і все. Pages перезбирається сам за 1–2 хвилини
- перевіряти результат **тільки з жорстким перезавантаженням** (Ctrl+Shift+R) — інакше
  браузер покаже кеш і здасться, що правка не застосувалась

Решта файлів: `clients/*.png` — логотипи клієнтів, `og-cover.jpg` — прев'ю для соцмереж
(1200×630, на нього вказує `og:image`).

## Як орієнтуватися у файлі

**Не покладайтеся на номери рядків** — вони злітають після кожної правки. У файлі є
коментарі-якорі, шукайте по них:

```
/* ---------- header ---------- */        /* ---------- contact ---------- */
/* ---------- language switch ---------- */  /* ---------- footer ---------- */
/* ---------- hero ---------- */          /* ---------- clients ---------- */
/* ---------- sections ---------- */      /* ---------- reveal ---------- */
/* ---------- cards / packages ---------- */  /* ---------- particle logo ---------- */
/* ---------- process ---------- */
/* ---------- career ---------- */
/* ---------- faq ---------- */
```

Файл складається з чотирьох блоків у такому порядку:

1. **`<style>`** — усі стилі
2. **розмітка** — `<header>`, далі секції, далі `<footer>`
3. **`<script type="application/ld+json">`** — структуровані дані для Google
   (`ProfessionalService`: name, description, email, areaServed)
4. **`<script>` зі словниками `I18N`** — усі тексти обох мов + логіка перемикання
5. **`<script>` з поведінкою** — sticky header, reveal на скрол, анімована лапа на канвасі

## Секції сторінки, у порядку появи

`hero` → `#clients` → `#services` → `#process` → `#packages` → `#faq` → `#career` → `#contact` → footer

Пункти навігації ведуть на `#services`, `#process`, `#packages`, `#career`, `#contact`.
Hero має дві кнопки: `hero.cta1` → `#contact`, `hero.cta2` → `#packages`.

Секції `#work` (портфоліо з роликами) **більше немає** — її прибрали коммітом

портфоліо — його треба відбудовувати з нуля, а не «повертати».

## Система мов — головне, де легко напартачити

Усі тексти лежать в об'єкті `I18N` з двома словниками: `I18N.en` і `I18N.uk`.
Англійська — мова за замовчуванням.

**Залізне правило: кожен ключ має існувати в обох словниках.** Зараз по 102 ключі в
кожному, розбіжностей нуль. Якщо додати ключ лише в `en`, українська версія покаже
англійський текст — і це не впаде з помилкою, а просто тихо з'явиться на живому сайті.

Після будь-якої правки текстів — звірити набори ключів:

```bash
python3 -c "
import re
s=open('index.html',encoding='utf-8').read()
d={l:set(re.findall(r'\"([a-zA-Z0-9_.]+)\"\s*:', re.search(r'\n  '+l+r': \{(.*?)\n  \}',s,re.S).group(1))) for l in ('en','uk')}
print('en:',len(d['en']),'uk:',len(d['uk']))
print('тільки en:',sorted(d['en']-d['uk']))
print('тільки uk:',sorted(d['uk']-d['en']))
"
```

Як це працює:

- у розмітці — атрибут `data-i18n="ключ"`, його `innerHTML` підміняється з словника
- `data-i18n-aria="ключ"` — те саме для `aria-label`
- префікси ключів: `meta`, `mail`, `lang`, `nav`, `hero`, `clients`, `services`,
  `process`, `packages`, `faq`, `career`, `contact`, `footer`
- `meta.*` керує `<title>`, `description`, `og:title`, `og:description`, `og:locale` —
  тобто правка цих ключів змінює те, що бачить Google і що показує прев'ю в месенджерах
- `mail.subject` і `mail.career` підставляються в тему листа `mailto:`
- вибір мови зберігається в `localStorage` під ключем `blackpaw-lang`
- порядок визначення мови у `detect()`: збережений вибір → `?lang=uk|en` в адресі → `en`
- поруч лежить **закомментована** функція `fromBrowser()` — якщо колись захочуть, щоб
  українські браузери одразу бачили українську, її розкоментовують і додають
  `|| fromBrowser()` у `detect()`

## Пастки, на яких легко зламати сайт

**Карусель логотипів клієнтів.** Усередині одного `.marquee-track` набір із 8 логотипів
**продубльований рівно 4 рази**, а анімація зсуває трек на `translateX(-25%)`. Ці два
числа пов'язані: додали логотип в одну копію — карусель почне дьоргатись. Правити треба
всі 4 копії, а якщо змінюється кількість копій — перераховувати і відсоток у
`@keyframes marq`.

Копії 2, 3 і 4 позначені `aria-hidden="true"` — і це не косметика. По цьому атрибуту
правило `.marquee-track > [aria-hidden="true"]{display:none}` прибирає дублікати під
`prefers-reduced-motion: reduce`, де карусель не їде, а логотипи просто переносяться
в кілька рядів. Новий логотип без `aria-hidden` у копіях 2–4 зачитається скрінрідером
чотири рази і вилізе четвертим дублем у режимі зменшеного руху.

**Пошта.** `info@paw.black` зустрічається у 5 місцях: три `mailto:`-посилання,
блок `ld+json` і константа `EMAIL` у скрипті. Міняти всі п'ять.

**Навігація на вузьких екранах** прибирає пункти по одному, не всі разом:

| Ширина | Що зникає |
|---|---|
| ≤900px | шрифт навігації меншає |
| ≤780px | `services` |
| ≤640px | `packages` |
| ≤540px | `process` |

Додали пункт у меню — додайте йому місце в цій драбинці, інакше на телефоні
навігація поїде в два рядки.

**Анімована лапа в hero** — не картинка, а канвас `#particles`. Контур лапи
зашитий у масив `PAW` (п'ять контурів опорних точок: подушечка + 4 пальці),
частинки з нього *вирізаються*. Під `prefers-reduced-motion: reduce` малюється
статичний кадр через `drawStatic()`. Руками координати не правити.

**Поява на скрол.** Клас `.reveal` + `IntersectionObserver`, зараз 22 елементи.
Затримка рахується як `(i % 4) * 70ms` по порядку в документі — тобто додавання або
видалення елемента з `.reveal` трохи змінює ритм появи всіх наступних. Це
косметика, не баг, але якщо хтось скаже «анімація стала інша» — причина тут.

## Чек-лист перед коммітом

1. набори ключів `en` і `uk` збігаються (скрипт вище)
2. сторінка відкрита локально і перевірена в обох мовах — `index.html` і `index.html?lang=uk`
3. навігація та hero не поїхали на вузькому екрані
4. якщо правили тексти в `meta.*` — перевірити, що `<title>` міняється при перемиканні мови
5. `git status` чистий від тимчасових файлів
6. `README.md` не суперечить тому, що змінилось
